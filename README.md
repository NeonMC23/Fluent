## Overview

Fluent is a local AI-powered translation application designed to provide high-quality translations without relying on cloud services.

Built around the NLLB-200 family of multilingual translation models, Fluent supports more than 190 languages and dialects while keeping user data on the local machine.

The project focuses on:

- Privacy
- Simplicity
- Modern UI
- High translation quality
- Local execution
- Theme customization

## Translation Engines

Fluent uses two translation models depending on the selected quality mode.

### Fast Mode

Model:

facebook/nllb-200-1.3B

Designed for:

- Lower-end hardware
- Faster translations
- Reduced memory usage

### Accurate Mode

Model:

facebook/nllb-200-3.3B

Designed for:

- Maximum translation quality
- Better contextual understanding
- Improved support for low-resource languages
