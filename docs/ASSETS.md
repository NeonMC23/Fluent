# Branding and Icon Assets

No official Fluent logo exists in the repository. This cycle deliberately does
**not** invent one or add a placeholder that could be mistaken for the brand.

## Current state

| Asset | Status |
|---|---|
| Window icon | Generated at runtime in `crates/fluent-gui/src/main.rs` as a 64×64 RGBA turquoise circle with two white lines. It is a functional placeholder, not an approved logo. |
| Desktop/launcher icon | None installed by default. `install.sh --icon FILE` installs an SVG under the hicolor theme and references it from the desktop entry. |
| Windows `.ico` | None. |
| macOS `.icns` | None; no `.app` bundle exists. |
| Screenshots | `src/image1.png` and `src/image2.png` are UI screenshots used by the README, not icons. |
| Social/preview image | None. |

The installer handles a missing icon gracefully: the desktop entry simply omits
the `Icon=` line.

## Requirements for an official asset

A future brand package should provide:

- **Master**: SVG, square canvas (at least 512×512), transparent background,
  no text below 64 px, readable on light and dark backgrounds.
- **Linux**: 256×256 and 512×512 PNGs for `hicolor/256x256/apps/` and
  `hicolor/512x512/apps/`, or the SVG used by `--icon` now.
- **Windows**: multi-resolution `.ico` containing 16, 24, 32, 48, 64, 128 and
  256 px images.
- **macOS**: `.icns` generated from the 1024×1024 master (16–1024 px slices).
- **Window icon**: a 64×64 or 128×128 RGBA image embedded or generated by the
  GUI; the current generated icon should be replaced once a brand exists.
- **Monochrome/tray variant** if a tray icon is added later.
- **Colour specification**: exact sRGB values and light/dark variants so the
  icon matches the UI accent palette.

## What not to do

- Do not copy a third-party logo or use Meta/NLLB marks as Fluent branding.
- Do not commit a temporary icon and later replace it silently; icons are
  cached by desktop environments and become part of the application identity.
- Do not add platform icons until the master asset is approved; the installer
  is ready to take an SVG when that happens.

## Integration points

- Linux: `install.sh --icon path/to/icon.svg`, then desktop entry `Icon=io.fluent.Fluent`.
- Windows: embed the `.ico` through the executable/bundle metadata once a
  Windows packaging path exists.
- macOS: include the `.icns` in the future `Fluent.app` bundle and `Info.plist`.
